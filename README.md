# Kflix Asset Repository

This repository contains all visual assets, media files, and design resources used across the Kflix streaming platform applications.

## 📁 Repository Structure

* `/branding` — Logos, icons, and official color palettes.
* `/banners` — Hero images and promotional web banners.
* `/thumbnails` — Placeholder cards for video titles.
* `/ui` — Custom buttons, vectors, and interface components.

## 🚀 Usage

### Cloning the Repository
To use these assets in your local development environment, clone this repository directly into your project's asset folder:
```bash
git clone https://github.com
```

### CDN Alternative
For production environments, link directly to the raw asset URL to save bandwidth:
```text
https://githubusercontent.com
```

## 🎨 Asset Guidelines

* **Format**: Use SVG for icons, WebP for images, and PNG only when transparency is required.
* **Resolution**: Banner assets must maintain a 16:9 aspect ratio with a minimum width of 1920px.
* **Compression**: Run all new images through an optimization tool before pushing changes.

## 🛠️ Contribution Workflow

1. Create a new branch for your specific assets.
2. Place files in the appropriate category folder.
3. Submit a Pull Request for design team review.
